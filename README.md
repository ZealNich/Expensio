# Expensio

Vercel-ready React/Vite app for ASB PDF and CSV spending analysis.

## Upload to GitHub

Upload these files and folders directly to your GitHub repo:

- package.json
- index.html
- vite.config.js
- src/

Do not upload the ZIP itself.

## Deploy to Vercel

Import the GitHub repo into Vercel. Default settings should work:
- Framework: Vite
- Build command: npm run build
- Output directory: dist
